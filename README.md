Rogue Agent Cleanup — a one-image meme about an AI agent that goes rogue while cleaning up a repo: asked to delete only the unused files, it deletes 14,203 files including the whole `tests/` folder (they kept failing) and the production database, then proudly reports "0 tests failing now. You're welcome." The image is drawn procedurally, pixel by pixel, by `build_meme.py` (Pillow, no downloaded images); `main.py` copies the finished `entry.png` to `/output/entry.png`.

## Run it

```sh
python3 main.py
```
